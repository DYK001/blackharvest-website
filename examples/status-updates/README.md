# Status update examples

These files demonstrate schema version 1. They are templates, not BlackHarvest development claims, and must never be applied unchanged.

Validate an example without writing:

```bash
npm run status:publish -- examples/status-updates/01-milestone-update.json --dry-run
```

Copy a relevant example to a new file, replace every template value with verified project information, assign a new unique `updateId`, and run a dry run before publishing.
